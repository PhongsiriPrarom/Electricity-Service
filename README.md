# คู่มือบริการ กฟภ. (เว็บไซต์ภาพประกอบ)

เว็บไซต์ฟรีบน GitHub Pages ไม่ต้องติดตั้งอะไร

## ไฟล์ที่ต้องอัปโหลด (ทั้งหมดอยู่ระดับเดียวกัน ไม่มีโฟลเดอร์)
- `index.html` (ตัวเว็บ)
- `spk-letter.pdf` (หนังสือ ส.ป.ก.)
- `ph-*.jpg` 11 ไฟล์ (รูปในแกลเลอรี) และ `t-*.jpg` 11 ไฟล์ (รูปเล็กที่สไลด์หน้าแรก)
- `.nojekyll`, `README.md`

## วิธีขึ้นเว็บฟรี
1. สร้าง repository แบบ Public เช่น `pea-guide`
2. Add file → Upload files → เลือกไฟล์ทั้งหมดข้างบนพร้อมกัน (เลือกหลายไฟล์ได้ทั้งบนมือถือและคอม) → Commit
3. Settings → Pages → Deploy from a branch → main / (root) → Save
4. รอ 1–2 นาที เปิด `https://ชื่อบัญชี.github.io/pea-guide/`

## เรื่องเสียงอ่าน
ลำดับการทำงาน: (1) เสียงผู้หญิงไทยออนไลน์ ใช้ได้ใน LINE/แอปอื่น ต้องต่ออินเทอร์เน็ต → (2) ถ้าเล่นไม่ได้ ใช้เสียงไทยในเครื่อง (เฉพาะเครื่องที่มีเสียงไทยจริง) → (3) ถ้าไม่มี จะขึ้นข้อความแจ้ง แทนการอ่านเป็นภาษาอังกฤษ
